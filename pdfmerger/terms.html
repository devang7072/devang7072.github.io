1. Overview and Permitted Use

PDF Merger is a high-performance Android document utility developed by Devang Bhumbhaliya. The Application provides tools for:

  • Selecting multiple PDF documents and merging them into a unified output file.
  • Custom page-range subset extraction and selective page inclusion.
  • Drag-and-drop sequential document reordering.
  • Custom text watermarking (with configurable rotation, opacity, font size, and color).
  • Local document history archiving, instant PDF previewing, sharing, and custom file export.
